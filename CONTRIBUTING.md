## 🛠️ How to Contribute

<a href="https://github.com/CrabbierDuke167/pywhiz/pulls">
  <img src="https://img.shields.io/badge/PRs_Welcome-22c55e?style=for-the-badge&logo=github&logoColor=white" alt="PRs Welcome" />
</a>

We welcome contributions from developers of all skill levels! If you want to add a new feature, fix a bug, or improve the documentation, follow these standard steps:

1. **Fork the repository** on GitHub.
2. **Clone your fork** to your local machine:
   ```bash
   git clone https://github.com/yourusername/pywhiz.git
   ```
3. **Create a new branch** for your feature or fix:
   ```bash
   git checkout -b feature-awesome-new-tool
   ```
4. **Write your code** (please follow our simple guidelines below!).
5. **Commit and push** your changes to your fork.
6. **Open a Pull Request (PR)** on the main repository and tell us what you built.

<br/>

### 📝 Coding Guidelines

> **Note:** Since this project is designed to be read and understood by beginners, we ask that you follow a few simple rules:

| Principle           | Description                                                                                              |
| :------------------ | :------------------------------------------------------------------------------------------------------- |
| **Easily Readable** | Prioritize simplicity and clarity over complex, "clever" one-liners.                                     |
| **Clean Comments**  | Briefly explain _why_ your code does something if it isn't immediately obvious.                          |
| **Wise Naming**     | Use descriptive, intuitive names for your variables and functions.                                       |
| **Short & Focused** | Write small, focused functions that do exactly _one_ thing well without requiring external dependencies. |

<br/>

## 🐛 How to Report Errors and Issues

<a href="https://github.com/CrabbierDuke167/pywhiz/issues">
  <img src="https://img.shields.io/badge/Report_an_Issue-ef4444?style=for-the-badge&logo=github&logoColor=white" alt="Report an Issue" />
</a>

If you find a bug, something isn't working right, or you just have a great idea for a new feature, let us know!

1. Head over to the **[Issues tab](https://github.com/CrabbierDuke167/pywhiz/issues)** on our GitHub repository.
2. Click the **New Issue** button.
3. **Describe the issue:** Tell us what you were trying to do.
4. **Include the error message:** Copy and paste the exact Python error or traceback you got. (Use code blocks!)
5. **Steps to reproduce:** Briefly explain the steps or the code you ran so we can trigger the exact same error on our computers and fix it quickly!
